# Formal Model Workspace Structure

This directory is the single source of truth for the EnergyPlus-surrogate workflow.

## Active code
- `script/batch_runner_v7.py`: batch EnergyPlus runner and post-processing
- `script/03_surrogate_v7.ipynb`: surrogate training, evaluation, and figure generation
- `script/work.ipynb`: scratch notebook if still needed

## Active outputs
- `output/lhs/`: LHS sample matrices and metadata
- `output/results/`: canonical results tables and model-performance tables
- `output/figures/detached/`: detached figures generated by the notebook
- `output/figures/semi/`: semi-detached figures generated by the notebook
- `output/models/detached/`: detached surrogate model artefacts
- `output/models/semi/`: semi-detached surrogate model artefacts
- `output/runs/detached/`: detached EnergyPlus run directories
- `output/runs/semi/`: semi-detached EnergyPlus run directories

## Archive
- `output/archive/pilots/`: pilot and one-off test runs
- `output/archive/validation/`: validation mini-batches and validation run directories
- `output/archive/results/`: previous result backups before target-definition changes
- `output/archive/legacy_figures/`: stale figure exports kept only for record
- `script/archive/`: duplicate or superseded notebooks moved out of the active path

## Canonical result files
- `output/results/results_v7.csv`
- `output/results/results_v7_semi.csv`
- `output/results/model_performance.csv`
- `output/results/model_performance_semi.csv`

Do not use files from the OneDrive copy as execution sources. Use only the local project under `~/Projects/dissertation`.
