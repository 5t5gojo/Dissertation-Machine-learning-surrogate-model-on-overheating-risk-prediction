# corrected V2 全量温差取整核对结果

本轮使用 Projects 文件夹中 corrected V2 的全部 8,000 个案例、16,000 条占用区域逐时序列，只做后处理。未运行 EnergyPlus，未重训模型，未修改论文，未覆盖旧结果。

结论：方法研究的主线没有被推翻，但取整不是可以忽略的排版细节。C1 连续值普遍上升，DSY1 的 C3 和同区联合标记明显减少；TMYx 中“完全没有 C1 或联合标记”的说法只对原始温差代理定义成立。

## 计算口径

- 保持天气、占用日程、自适应温度上限及区域范围不变。每区夏季占用分母仍为 3,672 h；这里的占用判据是实际模型日程大于零，不代表真实占用已验证。
- 原始口径：C1 计入原始温差 >=1 K 的小时；C3 计入原始温差 >4 K 的小时。
- 取整口径：先将温差取最近整数，再分别应用 >=1 和 >4。主计算使用 NumPy rint 的半整数取偶数规则，并独立验算半整数远离零的进位规则。全部数据中没有正半整数温差，两种取整规则的结果完全一致。
- C1 标记为超过 3%，C2 标记严格为 >6。C2 的现有阶梯式计算保持不变。C3 标记为存在至少一个符合条件的夏季小时。
- 联合标记必须在同一占用区域中有至少两项标记，再汇总到住宅；没有把不同区域的单项最坏值拼成住宅联合标记。
- 以下都是固定模型假设下的指标敏感性结果，不是正式 TM52/TM59 合规认证。

## C1 连续值变化

表中均值是住宅 worst-zone C1 的均值；变化单位为百分点，不是相对百分比。各组均为 2,000 例。

| 天气与户型 | 原始均值 | 取整均值 | 平均增加 | 单例最大增加 | 数值增加的案例 |
|---|---:|---:|---:|---:|---:|
| TMYx detached | 0.1676% | 0.3776% | 0.2100 个百分点 | 1.1438 个百分点 | 1,846 |
| TMYx semi | 0.0778% | 0.2113% | 0.1336 个百分点 | 0.9259 个百分点 | 1,573 |
| DSY1 detached | 1.5600% | 1.8319% | 0.2719 个百分点 | 1.9336 个百分点 | 2,000 |
| DSY1 semi | 1.4020% | 1.6706% | 0.2686 个百分点 | 1.3889 个百分点 | 2,000 |

共 7,419/8,000 例的住宅 C1 连续值增加。平均增量不大于 0.272 个百分点，但这并不说明训练目标变化可忽略，尤其 TMYx 原始 C1 本身较小。没有根据这次后处理推断取整目标的 R2 或 SHAP。

## 阈值标记变化

箭头表示“原始温差计数 -> 取整温差计数”。C2 固定列没有变化。

| 天气与户型 | C1 >3% | C2 >6 固定 | C3 非零 | 同区两项联合标记 |
|---|---:|---:|---:|---:|
| TMYx detached | 0 -> 1 | 784 | 0 -> 0 | 0 -> 1 |
| TMYx semi | 0 -> 0 | 392 | 0 -> 0 | 0 -> 0 |
| DSY1 detached | 15 -> 46 | 2,000 | 1,969 -> 1,851 | 1,969 -> 1,851 |
| DSY1 semi | 3 -> 18 | 2,000 | 1,822 -> 1,508 | 1,822 -> 1,508 |

479 个案例至少有一个标记改变：TMYx detached 1 个、TMYx semi 0 个、DSY1 detached 149 个、DSY1 semi 329 个。

C1 共新增 47 个标记，没有减少。C3 共减少 432 个标记，没有新增。联合标记新增 1 个、减少 432 个；这些与单项变化重叠，不能相加当作独立案例数。

TMYx 新增案例为 detached `run_0768`：Space 101 的 C1 从 73/3,672 h = 1.9880% 变为 115/3,672 h = 3.1318%。该区 C2 为 30，C3 为零，因此新增的是同区 C1+C2 联合标记，不是跨区拼接或新增 C3。

取整后的 DSY1 C1 标记比例为 detached 2.30%、semi 0.90%；C3 和同区联合标记比例为 92.55%、75.40%。C3 最坏区域小时数均值分别从 6.7860 降至 3.7715 h、从 4.2825 降至 2.2155 h。

## 对论文主要结论的影响

### 需要调整或限定的说法

1. “TMYx 没有 C1 或联合标记”必须注明原始温差代理定义。取整后 detached 有 1/2,000 例，semi 仍为零。不能把这一例写成正式 TM52 不合规住宅。
2. “两户型 DSY1 C2/C3 都接近饱和”不宜无条件保留。C2 仍然全部超阈值，但取整后 semi 的 C3/联合标记为 75.40%，应改为具体比例或“较高发生率”。
3. 若决定以取整后的 C1 替换训练目标，原 He 模型的 R2、MAE、RMSE、SHAP 不能直接转用于新目标。是否重训是下一步决策，本轮没有执行。

### 本轮没有推翻的说法

1. DSY1 相对该 TMYx 文件仍产生更强连续响应。取整后的 C1 在全部 4,000 对天气样本中增加；平均增加 detached 1.4543、semi 1.4593 个百分点。
2. 两套天气下，semi 的 C1 均值仍低于 detached，但不是所有配对住宅都低于 detached，不应写成普遍的逐案例规律。
3. 峰值温度、夏季和全年夜间 >26°C 小时数、供暖需求均不使用这次改变的温差取整。这些原始值逐案复算一致。峰值预测较稳、严重夜间尾部误差大等原有结果没有因本轮后处理而改变；本轮没有重新评价这些已训练模型。
4. DSY1 仍为单独天气下重训的补充实验，不能改称冻结 TMYx 模型的跨天气迁移。天气来源、地点与情景差异也依旧存在。

最稳妥的下一步是先决定论文保留原始 proxy 并报告敏感性，还是正式把 C1 训练目标换成取整版本。两种选择都必须明确区分数据版本，不能只替换阈值计数却继续把旧 He 模型称为针对新定义的评价。

## 验证与文件

- 全部 8,000 例从逐时输出复现旧版 audit 指标，再计算取整结果；没有跳过失败案例。
- 全部 16,000 区域序列通过独立区间计数验证：取偶数口径下 C1 相当于原温差 >0.5 K，C3 相当于原温差 >4.5 K。
- 7 项单元测试覆盖边界、严格阈值、同区联合及联合标记增减。
- 4,725 个受保护文件前后校验通过；8,000 个逐时 CSV 和对应运行 IDF 均通过输入及结束时的 SHA-256 检查。
- `results/REPORT.md` 提供英文计算定义、完整汇总及边界说明。
- `results/case_comparison.csv` 和 `results/zone_comparison.csv` 分别包含全部逐案例和逐区对照。
- `results/flag_transitions.csv` 提供完整双向翻转计数，`results/changed_flag_cases.csv` 可定位全部变化案例。
- `results/verification.json` 与哈希清单记录来源保全及完成状态。

取整核对的规范背景来自[英国政府过热研究报告第 7–8 页](https://assets.publishing.service.gov.uk/media/5d91ca2ded915d556d8e7b64/Research_into_overheating_in_new_homes_-_phase_1.pdf)。本轮只核对温差取整，未声称对原始 TM52/TM59 全部条款重新完成合规审核。
